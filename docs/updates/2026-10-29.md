# October 2026 Resource Guide

**Checked: 2026-10-29.** This update adds 34 resources: 33 in the egocentric
catalog and one robot-only adjacent dataset. The entries span August-October
publications and releases; publication date is not the date of inclusion here.

Each entry identifies the creator separately from the account or organization
distributing the release. Checks cover official papers, project pages, release
notes and file listings, not full-corpus downloads or reproduced experiments.
Older catalog entries retain their own verification dates.

## What is available

### SOMA

1,632 human-verified questions on body configuration, motion dynamics, and temporal reasoning from first-person video.

The paper announces benchmark, training data, and code; downloadable artifacts were not verified.

[Paper](https://arxiv.org/abs/2610.36384) / [Project](https://cnai.epfl.ch/soma).

### ProactEgoMem

300 daily-life and 100 scientific clips; 1,500 QA items testing proactive information capture, state tracking, and location tracking.

Annotations, evaluation code, and leaderboard are available. Obtain source video separately. Benchmark data, including dev items, must not be used for training.

Terms: CC-BY-NC-4.0 annotations; source-video terms apply.

[Paper](https://arxiv.org/abs/2610.30089) / [Code](https://github.com/mayhugotong/ProactEgoMem) / [Data](https://huggingface.co/datasets/Meikel/ProactEgoMem) / [Leaderboard](https://www.codabench.org/competitions/18340/).

### STOU

Paper: 2,902 video-audio/text safety queries; gated release: 1,952 instances over 713 source clips, separating harm understanding from refusal.

The public card documents a smaller gated release than the paper. Clip reconstruction instructions and annotations are listed; evaluation code is still marked coming soon.

Access: Hugging Face agreement; source videos acquired separately.

Terms: CC-BY-NC-4.0 annotations; source-video terms apply.

[Paper](https://arxiv.org/abs/2610.17728) / [Data](https://huggingface.co/datasets/Chloeing/STOU).

### EgoVoice

Proactive spoken assistance from HoloAssist-derived video/audio streams, jointly evaluating speech timing and guidance content.

The project schedules code, models, and dataset for November 2026; these assets are not yet verified as released.

[Paper](https://arxiv.org/abs/2610.12248).

### Ropedia W0

Camera-pose and skeleton-conditioned loco-manipulation world model trained with 10K human and 3K robot hours; 5B pre-trained and mid-trained checkpoints released.

5B inference and two checkpoints are available. A14B, benchmark-tuned checkpoints, evaluation package, and post-training code remain pending. The 13K-hour training mixture is not a separately verified full data release.

Terms: Apache-2.0 code; CC-BY-NC-4.0 weights; upstream model terms apply.

[Paper](https://arxiv.org/abs/2610.26855) / [Project](https://ropedia.github.io/ropedia-w0/) / [Code](https://github.com/Ropedia/ropedia-w0) / [Weights](https://huggingface.co/ropedia-ai/Ropedia-W0).

### Xp-Teleop

27 Unitree G1 humanoid episodes, 543 action segments, and 96,064 frames with clean head RGB, keypoints, masks, calibration, and IMU.

Teleoperation data are downloadable; the W0 evaluation-code package is a separate, pending release.

Robot head-camera teleoperation, not human-worn capture; complements human-to-robot world-model evaluation.

Terms: cc-by-4.0.

[Paper](https://arxiv.org/abs/2610.26855) / [Data](https://huggingface.co/datasets/ropedia-ai/Xp-Teleop).

### TouchScale

Current release: 100 hours, 15,324 episodes, 929 tasks, and 193 object meshes; synchronized head RGB-D, wrist RGB, and 880 tactile taxels per hand.

The full 500-hour corpus is planned for release before November 2026; only the documented 100-hour portion is counted as available.

Access: Hugging Face agreement required.

Terms: cc-by-nc-4.0.

[Paper](https://arxiv.org/abs/2610.10288) / [Project](https://touch-scale.github.io/) / [Data](https://huggingface.co/datasets/2077AIDataFoundation/TouchScale).

### EMBER-Bench

189 recorded household tasks and 699 history-dependent questions: 548 next-action predictions and 151 causal traceback questions.

Benchmark media, portable catalog, and evaluation CLI are available. The maintained evaluator is not an exact reproduction of the paper's frozen leaderboard.

Terms: cc-by-nc-4.0.

[Paper](https://arxiv.org/abs/2610.05013) / [Code](https://github.com/ZHAOAlexGoat/EMBER-Bench) / [Data](https://huggingface.co/datasets/Alexzhao0605gt/EMBER-Bench).

### Ego-SpaCR / SpaC-MEM

620 ScanNet video sessions, 95 task-oriented conversations, and 3,100 evaluation queries for spatially grounded conversational memory.

Code and a 3,218-question annotation ZIP are available; use the 3,100 official_eval questions for the reported protocol. Obtain ScanNet separately. Free-text judging and other paper baselines are outside the released scorer.

ScanNet-derived first-person spatial conversations, not a newly captured wearable corpus.

[Paper](https://arxiv.org/abs/2610.05526) / [Code](https://github.com/joeliang0520/SAPCR-MEM).

### PWM / PWM-Bench

150 first-person world-model customization tasks across indoor, outdoor, and Minecraft scenes; 300 paired support/test videos and 33,750 frames.

Support and test segments are disjoint within each scene, not a cross-scene generalization split. Reuse terms are not summarized by a single dataset license.

Access: Public benchmark files and code; consult upstream video and base-model terms.

[Paper](https://arxiv.org/abs/2610.04920) / [Code](https://github.com/AIGeeksGroup/PWM) / [Data](https://huggingface.co/datasets/AIGeeksGroup/PWM-Bench).

### EgoExo-Next

2,503 human-curated four-choice questions from six ego/ego-exo sources, testing visual next-state prediction and cross-view correspondence.

Image options, input metadata, and answers are released. Dataset-viewer image-row counts are not benchmark question counts.

Terms: Non-commercial research annotations; inherited source-image terms.

[Paper](https://arxiv.org/abs/2610.04506) / [Data](https://huggingface.co/datasets/yutongli2024/EgoExo-Next).

### NextMe-800 / NextAct

795 hours from one Aria wearer across a 126-day span, with 527 recordings on 114 recording days; gaze, audio, five-level captions, and a 1,500-point NextAct benchmark.

The card lists 8.81 TB of recordings plus captions and benchmark scripts. NextAct also uses EgoLife; one wearer's long history does not establish population diversity.

Access: Hugging Face research-use and privacy agreement.

Terms: CC-BY-NC-4.0; additional research/privacy conditions.

[Paper](https://arxiv.org/abs/2610.01461) / [Data](https://huggingface.co/datasets/mmm8383/NextMe-800).

### Argus

Dense video annotation and data-quality checks across LeRobot, MCAP, and video archives; publisher reports 3,546 audited human/robot episodes across nine datasets.

Public annotation harness and inspection outputs; generated quality judgments are not independently validated ground truth.

Mixed human-ego and robot data tooling, with explicit support for OpenAoE, Gen-HumanEgo, and Egocentric-100K.

[Project](https://pantheon.inc/blog/argus) / [Code](https://github.com/Pantheon-Industries-Inc/argus).

### APM-Bench

549 sessions in 104 trajectories, with 2,719 candidate interactions for cross-session memory, current-scene perception, and adaptive response.

The 549 session videos are hosted; annotations and evaluation code are still being prepared. Do not treat the video upload as a complete runnable benchmark.

Terms: CC-BY-NC-4.0; source-dataset terms apply.

[Paper](https://arxiv.org/abs/2609.37559) / [Code](https://github.com/Jianguo-Huang11/APM-Bench) / [Data](https://huggingface.co/datasets/Jianguo-Huang11/APM-Bench).

### HumanVerse-500 / lambda_0

Reported 500-hour wearable corpus synchronizing egocentric video with body and hand motion, used by the lambda_0 humanoid loco-manipulation policy.

The paper promises code, models, and data; a downloadable release was not verified. First submission was September 30 despite the October arXiv identifier.

[Paper](https://arxiv.org/abs/2610.00438).

### Ego4WAM

Controlled world-action-model study separating human-robot alignment, duration, task diversity, action labels, and training-stage effects.

Paper verified; executable code and model weights were not verified.

[Paper](https://arxiv.org/abs/2609.40341).

### IronMind

Humanoid VLA pretraining on human ego video and robot data using camera-space actions; studies budgets from 250 to 10,000 hours.

The project provides the report and demonstrations; code, checkpoints, and the training corpus were not verified as downloadable.

[Paper](https://arxiv.org/abs/2609.39403).

### EgoTSR++ / SpatialLogic-Bench

Goal-conditioned progress reasoning from bidirectional state pairs, with order-robust comparisons and long-horizon failure/recovery evaluation.

A distinct follow-up to EgoTSR; paper verified, runnable model and benchmark releases not verified.

[Paper](https://arxiv.org/abs/2609.31751).

### EgoWild / EgoWild2Dex

Reported 538.9 hours, 179,049 episodes, 125,961 task descriptions, and 1,282 object categories from in-the-wild head-camera manipulation.

The paper announces data, models, and code. The reported corpus size is not a verified downloadable release size.

[Paper](https://arxiv.org/abs/2609.23755).

### SlugTrails

Aria recordings across three campus buildings and six floors, with CAD floor plans, survey-aligned trajectories, and single-frame, sweep, and walking-stream protocols.

A downloadable package, checksums, and viewers are provided. Public video is anonymized; original unblurred VRS is not distributed.

[Paper](https://arxiv.org/abs/2609.19876) / [Code](https://github.com/Head-inthe-Cloud/SlugTrails) / [Data](https://huggingface.co/datasets/Head-inthe-Cloud/SlugTrails).

### XPACE

Joint future-video and action modeling from heterogeneous human and robot experience, including simulated recoveries for policy improvement.

Technical report and demonstrations verified; downloadable model assets were not verified.

[Paper](https://arxiv.org/abs/2609.17372).

### EEH-R / EventEgoHands++

Real event-camera hand dataset with about 1M annotated frames, 85 sequences, eight participants, and 2.36 hours; accompanies an expanded synthetic N-HOT3D.

Training, evaluation, and viewer code is public; dataset access is form-based.

Access: EEH-R and N-HOT3D request forms linked from the official repository.

Terms: CC-BY-NC-4.0 code; dataset request terms apply.

[Paper](https://arxiv.org/abs/2609.17189) / [Code](https://github.com/ryhara/EventEgoHandsV2).

### EgoPathBench

31,852 training, 1,345 validation, and 1,111 benchmark questions for traversability, waypoint routes, and intent-conditioned paths from first-person RGB.

File-based release with 36 archives and checksums; use the corrected benchmark_evalfix labels. A dataset-viewer format error does not mean the archives are unavailable.

Terms: cc-by-nc-sa-4.0.

[Paper](https://arxiv.org/abs/2609.16610) / [Data](https://huggingface.co/datasets/runder1/EgoPathBench).

### HuRo

Reported 630K robotized episodes and 142M frames from five human egocentric sources; aligns rendered robot observations with retargeted actions.

Robotization pipeline code is available; the project does not yet provide a verified full-dataset download. Source-video rights still apply.

[Paper](https://arxiv.org/abs/2609.10706) / [Code](https://github.com/3587jjh/HuRo).

### MINT / EgoPipeline

Joint world-space camera and two-hand trajectory prediction; public checkpoint, training/inference code, EgoPipeline, and non-video annotations covering 1,021 hours.

Source videos are not redistributed; separately licensed MANO and optional pipeline assets must be obtained from their providers. Pseudo-labels are not motion-capture ground truth.

Terms: MIT original code; upstream models and MANO have separate terms.

[Paper](https://arxiv.org/abs/2609.04958) / [Code](https://github.com/wuji-technology/wuji-ego-mint) / [Data](https://huggingface.co/datasets/ZZJAsher/wuji_ego_mint) / [Weights](https://huggingface.co/ZZJAsher/mint_v1).

### TempCloze

1,521 videos from seven sources for selecting a missing middle clip; separates semantic plausibility, temporal alignment, and progression.

The Hugging Face package provides source identifiers and gap boundaries, not a self-contained video corpus. Obtain source footage under its own terms.

Mixed-source benchmark centered on long-take and egocentric video; not all source footage is wearable capture.

[Paper](https://arxiv.org/abs/2609.01515) / [Code](https://github.com/CedricPei/Temporal-Cloze) / [Data](https://huggingface.co/datasets/CedPei/TempCloze).

### Eidon Tracker POV

1,273.8 hours and 13,451 head-camera recordings from 27 contributors, paired with seven-slot upper-body IMU streams at 24 Hz.

Join video with the separate tracker-pov-imu repository on recording_id; they are one corpus, not additive hours. Some rigs lack slots. Video is not face-blurred and may contain incidental private information.

Terms: cc-by-4.0.

[Project](https://eidonai.online/) / [Data](https://huggingface.co/datasets/eidon-ai/tracker-pov).

### Eidon Egocentric POV

305.7 hours and 1,370 head-mounted video-only recordings from 37 contributors, without the Tracker POV IMU harness.

A Storage Bucket, not a datasets-library repository. Contributor identities overlap with Tracker POV, so cross-corpus subject splits require care.

Terms: cc-by-4.0.

[Project](https://eidonai.online/) / [Data](https://huggingface.co/buckets/eidon-ai/egocentric-pov).

### Eidon Capture and Playback Tools

Public wearable IMU hardware/firmware, glove designs, and Eidon Sim for arm kinematics and video-synchronized trajectory playback.

Archived capture ecosystem; Eidon has ceased operations and the old mobile-app backend is shut down. Sim is MIT; check each hardware/code repository's terms separately.

[Project](https://github.com/Eidon-AI/eidon-sim) / [Code](https://github.com/Eidon-AI/eidon-tracker).

### EgoViz-120

120.4 hours, 5,392 clips, and 12 workplace categories; stereo RGB-D, wrist cameras, three IMUs, hand pose, and action labels in MCAP.

The dataset repository holds documentation; 7.25 TB of media and metadata live in the linked Storage Bucket. The empty dataset-viewer warning does not describe the bucket.

Terms: cc-by-4.0.

[Data](https://huggingface.co/buckets/humaidtech/EgoViz-120).

### AnyWorld

Factorizes action, camera, and embodiment to recompose unpaired human interactions into robot-native video-action experience.

Image-editor training/inference and world-model inference code are public. External base components and adapted checkpoint setup follow the repository's model-weight guide.

Terms: Apache-2.0 code; external model terms apply.

[Paper](https://arxiv.org/abs/2608.29242) / [Code](https://github.com/xpeng-robotics/AnyWorld).

### EgoArgus

6,978 understanding examples over 3,719 source-derived clips and 789 intervention decisions over 311 hosted videos.

Annotations and evaluation code are public; understanding videos require separate source access. The repository calls itself a release draft and explicitly says reuse rights are not yet granted. Fifteen rows have out-of-option labels.

[Paper](https://arxiv.org/abs/2608.25561) / [Code](https://github.com/NYCU-NLP-Lab/EgoArgus) / [Data](https://huggingface.co/datasets/tommytyc/EgoArgus).

### RealTimeVideo-Instruct-112K

112,102 real-time QA/caption instruction samples, including 22,493 Ego4D and 6,861 Aria Digital Twin samples; queries occur when evidence first becomes visible.

Annotations only; fetch each source-video collection separately. The ADT subset has stricter non-commercial/share-alike terms.

Mixed ego and general-video annotation corpus; only the named egocentric subsets are first-person.

Terms: CC-BY-4.0 annotations except ADT subset: CC-BY-NC-SA-4.0.

[Paper](https://arxiv.org/abs/2608.13416) / [Code](https://github.com/zeyun-zhong/StreamTTT) / [Data](https://huggingface.co/datasets/zeyun-zhong/RealTimeVideo-Instruct-112K).

### EgoDatasets

Dataset-centric taxonomy of 96 resources from 2008-2026: 79 core egocentric/multiview datasets and 17 contextual exocentric datasets.

Open-access survey published October 16; distinguishes native anticipation support from adapted and post-hoc protocols.

[Paper](https://doi.org/10.3390/app162010268).

## Updated releases

- **[Open-AoE](https://huggingface.co/datasets/inclusionAI/OpenAoE-2000h)** (`open`): Full approximately 2,000-hour smartphone first-person release, with 3-hour nano and 100-hour tiny subsets, camera trajectories, MANO reconstructions, and atomic actions. The October 17 log confirms all approximately 2,000 hours uploaded. Custom dataset terms permit attributed research/commercial use; MANO-derived files have additional restrictions. Apache-2.0 applies to code, not the dataset.
- **[EgoHTR](https://egohtr.github.io/)** (`request`): 55 scene-aligned 4D human-motion sequences across seven challenging terrains, totaling 1.37 hours and about 150K frames from eight participants, with 36 multiview sequences and 0.7 hours of motion-capture ground truth. The 719 GB dataset is hosted behind a Hugging Face agreement. The project still labels code coming soon; data availability does not imply the reconstruction pipeline is released.
- **[EgoWearBench / Wearable AI Dataset](https://huggingface.co/datasets/facebook/wearable-ai)** (`request`): 700 validation samples per task across EgoConv conversational QA, EgoLongQA long-video QA, and EgoProactive streaming assistance; includes an evaluation starter kit. Official card now names the package EgoWearBench. The three 700-sample configurations and starter kit are gated by a Hugging Face agreement; sample counts should not be read as unique-video counts across tasks.
- **[SG-Ego / GLEN](https://francescapistilli.github.io/GLEN)** (`benchmark`): Approximately 18.7M frame-level and 3.8M clip-level scene graphs over Ego4D, with GLEN and a public graph-annotation pipeline. Frame and video graph Parquet packages are downloadable. These are annotations, not newly collected video; source Ego4D access and applicable derivative terms still matter.
- **[VIABench](https://github.com/MCG-NJU/VIABench)** (`partial`): 761 first-person videos, 46.9 hours, and 14,526 annotations for proactive reminders, assistive QA, and vision-guided interaction. The official Hugging Face dataset is live (about 69.3 GB). The linked GitHub repository remains README/assets-only; a complete runnable evaluator was not verified. Consult source-video terms rather than assuming a repository license covers every recording.
